# MSc Thesis as a Single-File HTML Document

A long-form **HTML** rendering of an MSc thesis in geography and geoinformatics.
The page demonstrates how an extended academic document - structured text,
headings, figures and tables - can be marked up semantically and presented
directly in a web browser.

## Contents

- \`HTML_01_page_MScThesis_Lemenkova.html\` - the complete thesis page.

## Technologies

HTML (semantic, single-file document).

## Usage

Open the \`.html\` file in any web browser to read the document.
